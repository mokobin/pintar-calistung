Ringkasnya: data belajar anak disimpan di perangkat Anda sendiri, tidak dikirim ke server kami. Kami tidak memasang iklan dan tidak memakai pelacak.

Siapa kami

Tongki Calistung dibuat dan dikelola oleh [nama pemilik / nama usaha] ("kami"). Kontak: [email atau WhatsApp].

Data yang disimpan di perangkat Anda

  • Nama panggilan anak (boleh nama samaran), tahap belajar, bintang, stiker, piala, rutinitas, dan catatan latihan.
  • Gambar hasil mewarnai.
  • Pengaturan suara dan musik.

Semua data ini tersimpan di penyimpanan browser (localStorage) di perangkat Anda. Kami tidak bisa melihatnya. Data terhapus bila Anda menghapus data situs/browser, jadi gunakan fitur Cadangan progres di Ruang Orang Tua untuk menyimpannya ke file.

Data yang dikirim saat aktivasi lisensi

Saat Anda memasukkan kode lisensi, aplikasi mengirim kode lisensi dan ID perangkat acak (dibuat aplikasi, tidak terkait identitas Anda) ke server lisensi kami di Cloudflare. Server memeriksa keabsahan kode ke Mayar (penyedia pembayaran) dan mencatat ID perangkat untuk membatasi jumlah perangkat per lisensi. Alamat IP dipakai sementara untuk mencegah penyalahgunaan (batas percobaan) dan dihapus otomatis dalam sekitar satu jam.

Pembayaran

Pembayaran diproses oleh Mayar (mayar.id). Data pembeli seperti nama, email, dan metode pembayaran dikelola Mayar sesuai kebijakan privasinya. Kami menerima informasi transaksi dari Mayar untuk keperluan lisensi dan bantuan pelanggan.

Layanan pihak ketiga

  • Suara pembaca. Aplikasi memakai suara bawaan browser. Di Microsoft Edge, suara "Online (Natural)" seperti Gadis diproses layanan Microsoft, sehingga teks yang dibacakan dikirim ke Microsoft untuk diubah menjadi suara.
  • Huruf (font). Tampilan huruf dimuat dari Google Fonts, sehingga browser menghubungi server Google.
  • Hosting. Aplikasi disajikan oleh Cloudflare.

Anak-anak

Aplikasi ditujukan untuk anak 3–7 tahun dan dirancang untuk dipakai bersama orang tua. Kami tidak meminta data pribadi anak. Proses pembelian dan aktivasi berada di balik tombol khusus orang tua.

Hak Anda

Anda dapat menghapus seluruh data dengan menghapus profil di Ruang Orang Tua atau menghapus data situs di browser. Untuk pertanyaan atau permintaan terkait data lisensi (misalnya menghapus catatan perangkat), hubungi [email].
